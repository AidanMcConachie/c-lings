# Intro

c-lings is a set of small exercises that teach you to read and write C, in
the spirit of [rustlings](https://github.com/rust-lang/rustlings).

Start `clings` in this directory and keep it running in a terminal while you
edit the exercises in your editor. Every time you save, clings recompiles and
re-checks the current exercise.
