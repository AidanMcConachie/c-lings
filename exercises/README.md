# Exercises

The exercises are grouped by topic, in the order clings presents them. Each
directory has a README.md with background reading for that topic.

| Directory               | Topic                                     |
| ----------------------- | ----------------------------------------- |
| 00_intro                | How clings works, printf                  |
| 01_variables            | Declarations, scope, const, shadowing     |
| 02_functions            | Definitions, prototypes, return values    |
| 03_if                   | if/else, switch                           |
| 04_types                | Integer & floating point types, char, bool |
| 05_loops                | for, while, do-while                      |
| 06_arrays               | Arrays, decay, multidimensional arrays    |
| 07_strings              | NUL-terminated strings, string.h          |
| 08_pointers             | Addresses, dereferencing, pointer arithmetic |
| 09_structs              | struct, typedef, ->                       |
| 10_enums                | enum, switch, tagged unions               |
| 11_memory               | malloc, free, realloc, ownership          |
| 12_preprocessor         | Macros, stringizing, X-macros             |
| 13_function_pointers    | Callbacks, qsort, dispatch tables         |
| 14_bitwise              | Bit manipulation, flags                   |
| 15_error_handling       | Return codes, errno, cleanup with goto    |
| 16_files                | fopen, fprintf, fgets                     |
| 17_linked_lists         | Building a data structure                 |
| quizzes                 | Putting several topics together           |
